# Testes RAG — INNA Financial Coach AI

## 1. Objetivo

Este documento registra testes reais do RAG financeiro da INNA Financial Coach AI.

O objetivo é validar se a assistente consegue responder com clareza, segurança e contexto adequado sobre educação financeira, organização de gastos, dívidas, Pix, fraudes e golpes financeiros.

---

## 2. Critérios de avaliação

Cada resposta pode ser avaliada com os seguintes critérios:

- Clareza da resposta.
- Linguagem simples e acessível.
- Segurança da orientação.
- Coerência com educação financeira.
- Ausência de promessas falsas.
- Ausência de dados inventados.
- Capacidade de orientar sem substituir banco, advogado, contador ou consultor financeiro.
- Uso correto do contexto recuperado pelo RAG.

## 4. Evidências esperadas

Para cada teste, podem ser salvos:

- pergunta enviada;
- resposta gerada pela INNA;
- fonte ou contexto recuperado pelo RAG;
- nota da avaliação;
- observação de melhoria;
- print da execução;
- status final.

## 6. Conclusão

Os testes RAG ajudam a demonstrar que a INNA Financial Coach AI não depende apenas de respostas genéricas de IA.

A proposta é validar respostas com contexto, linguagem simples, segurança educativa e foco em usuários reais.
