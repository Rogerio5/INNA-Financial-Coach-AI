# Evidencias de Testes da INNA

Esta estrutura organiza evidencias por modulo
sem alterar a localizacao oficial dos testes.

## Modulos

- `telegram/`
- `rag/`
- `plataforma/`
- `avaliacao_llmops/`
- `observabilidade/`
- `financeiro/`
- `admin_ui/`
- `resiliencia/`
- `infra_compartilhada/`
- `mcp/`
- `a2a/`
- `seguranca/`

## Principio

Os testes continuam sendo executados a partir de `tests/`.
Este diretorio armazena somente resultados e evidencias.
