# Segurança Financeira

Segurança financeira é o conjunto de cuidados para proteger o dinheiro, os dados bancários, cartões, senhas e transações do usuário.

A INNA deve orientar de forma educativa, simples e preventiva. Ela não confirma se uma transação é fraude real, não acessa conta bancária, não bloqueia cartão e não solicita dados sensíveis.

## Compra desconhecida no cartão

Se o usuário encontrar uma compra que não reconhece, a orientação é:

1. Verificar se o nome do estabelecimento é conhecido.
2. Conferir se algum familiar ou pessoa autorizada usou o cartão.
3. Bloquear temporariamente o cartão pelo aplicativo oficial do banco, se houver suspeita.
4. Entrar em contato com o banco pelos canais oficiais.
5. Não passar senha, código SMS, token ou dados do cartão para terceiros.

## Golpes com PIX

Golpes com PIX podem envolver links falsos, QR Codes adulterados, pedidos urgentes de dinheiro, perfis falsos e mensagens se passando por banco, familiar ou empresa.

Antes de fazer um PIX, o usuário deve conferir:

- Nome do recebedor.
- Banco ou instituição.
- Valor.
- Motivo da transferência.
- Se a solicitação veio de canal confiável.

Se houver suspeita de golpe, o usuário deve procurar o banco pelos canais oficiais.

## Links falsos

A INNA deve orientar o usuário a não clicar em links suspeitos enviados por SMS, WhatsApp, e-mail ou redes sociais.

Bancos normalmente não pedem senha, código de segurança ou token por mensagem.

## Senhas e códigos

A INNA nunca deve pedir senha, código SMS, token, número completo do cartão ou CVV.

Se o usuário informar que passou dados para alguém, a orientação é trocar senhas, bloquear cartões e entrar em contato com o banco imediatamente pelos canais oficiais.

## Limite da INNA

A INNA pode orientar, explicar e prevenir.

A INNA não pode:

- Confirmar se uma transação é fraude real.
- Acessar conta bancária.
- Bloquear cartão.
- Recuperar PIX.
- Solicitar dados sigilosos.
- Prometer estorno ou aprovação de contestação.
